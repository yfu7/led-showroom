# LED Wall Virtual Showroom v1 — Authoritative Feature Inventory (for LED Showroom v2 rebuild)

Source: `index.html` at the repo root (the v1 single-file app) (9560 lines; CSS/HTML lines 1–2128, ES-module JS from line 2129) plus `server.js` (proxy + splat pipeline) and `api/proxy.js` / `vercel.json` (static deploy proxy).
Merged from 12 section reads. Where readers disagreed, the source was re-read and the resolved fact is marked **[verified]**.

Global conventions (apply everywhere below):
- **World unit = 1 inch.** All 3D positions, sizes, camera distances and persisted coordinates are inches. Rotations are radians in state, degrees in UI.
- **Content space = wall pixels.** Content-window rects `{x,y,w,h}` are in wall pixels, origin top-left, y down; `wallWPx = cols×344`, `wallHPx = rows×258`.
- px↔in: `IN_PER_PX_W = 25.125/344 = 0.0730378 in/px (1.8552 mm)`, `IN_PER_PX_H = 18.875/258 = 0.0731589 in/px (1.8582 mm)`. Pitch is **not square** (px aspect 1.3333 vs physical 1.3311, 0.17 % difference) — v2 keeps independent X/Y pitch in the code path.
  - **[CAD supersedes]** v1's 25.125 × 18.875 × 2 in panel is the drawing's rounded inch call-out. The manufacturer's SolidWorks solid (`cad/step/LED iPoster - Panel.STEP`) is authored in inches at exactly **25.2 × 18.9 × 1.77 in** (exported as 640.08 × 480.06 × 44.958 mm), which makes the pitch exactly **square** at 640.08/344 = 480.06/258 = 1.8606977 mm (0.0732558 in/px in both axes). The manufacturer's 6 × 5 assembly (`cad/step/Veloxity LED iPoster Wall.STEP`) confirms it: panels butt flush, so 6 columns span exactly 151.2 in and 5 rows exactly 94.5 in. v2 uses the CAD numbers (`src/engine/ledwall/specs.ts`); every derived figure quoted below that comes from the panel size is therefore v1's, not v2's. The independent X/Y pitch plumbing stays — it just happens to be equal for this product.
- Wall is centred on its group origin; front (screen) face is local +Z at z = +1 in (v2: +0.885 in, half the CAD depth); default camera looks from +Z.
- "Active wall" = the wall whose render context is currently swapped into the module globals (`activeContextWallId`); "selected wall" = `state.selectedWallId` (normally the same).

## 3. Algorithms appendix (reimplementation-grade)

**A1. Unit conversions.** Inches = px × IN_PER_PX_W (x) / IN_PER_PX_H (y); feet = in/12. `pxToUnit(px, axis)`: px → `Math.round(px)`; panels → `+(px/(axis==='x'?344:258)).toFixed(2)`; pct → `+((px/(axis==='x'?wallWPx:wallHPx))·100).toFixed(1)`. `unitToPx` is the inverse with `Math.round`. `fmtFtIn(in) = floor(in/12) + "'" + (in % 12).toFixed(1) + '"'`. Sidebar feet = `(in/12).toFixed(1)`.

**A2. Column layout with corners (`computeColumnLayout`).** Inputs cols, gap (0.06 if bezels else 0), corners map afterCol → angleDeg. `step = 25.125 + gap`. Start x = 0, z = 0, walkAngle = 0. For c in 0..cols−1: record `{x, z, rotY: walkAngle}`; if c < cols−1: `hs = isCorner(c) ? 25.125/2 : step/2`; `x += cos(walkAngle)·hs; z −= sin(walkAngle)·hs`; if corner: `walkAngle += angle·π/180`; advance again by hs on the new heading. Subtract the centroid (mean x, mean z) of column centres so the wall origin is the centroid. Positive angle turns toward −Z (convex). Memoised until `invalidateLayout()`.

**A3. Straight segments (`computeSegments`).** `cornerCols = Set(afterCol)`; start = 0; for c in 0..cols−2: if c ∈ cornerCols push `{startCol:start, endCol:c}`, start = c+1; finally push `{start, cols−1}`. Segment centre = midpoint of first/last column; rotY = first column's; width = n·25.125 + (n−1)·gap.

**A4. Filtered pixel-grid shader (Inigo Quilez integral).** CPU: `PIXEL_PX = (cols·344, rows·258)`; `totalIn = (cols·25.125 + (cols−1)·g, rows·18.875 + (rows−1)·g)`; `cellIn = totalIn/PIXEL_PX`; `lineWidthIn = 0.36/25.4`; `halfLineCells = (lineWidthIn/2)/cellIn` per axis. Fragment: (a) if `uUseMask`: `cellId = floor(vUv·uPanelCells)`; sample mask at `(cellId+0.5)/uPanelCells`; `r < 0.5 → discard`. (b) `t = vUv·uGridCells`. (c) per axis `coverage(t,h)`: `d = max(fwidth(t), 1e-6)`; `twoH = 2h`; `a = t − d/2 + h`; `b = t + d/2 + h`; `F(y) = floor(y)·twoH + min(fract(y), twoH)`; `cov = clamp((F(b) − F(a))/d, 0, 1)` — exact integral of the periodic line indicator over the pixel footprint (converges to line density 2h when a pixel spans many cells → no moiré). (d) `alpha = (cx + cy − cx·cy)·uOpacity`; discard < 0.003; `gl_FragColor = vec4(uColor, alpha)`.

**A5. Sparse-cell bbox (`wallBBox`).** Parse each `'c,r'`, track min/max; `{cols: maxC−minC+1, rows: maxR−minR+1, minC, minR}`; empty → zeros; rect → `{cols, rows, 0, 0}`.

**A6. Contiguity BFS (`wouldStayContiguous`).** If cell not in set or size ≤ 1 → true. Start from the first existing orthogonal neighbour (none → true). BFS over 4-neighbours skipping the removed cell; return `seen.size === size − 1`. `classifyShapeEdit` as F23. `toggleShapeCell`: classify; return on last/no-adj/split; delete/add; `commitShapeEdit`. `paintShapeCell`: apply only if classification === `shapeDragMode`; return whether committed.

**A7. Camera fit / presets.** `b = allWallsBounds()`; `fov` rad; `span = max(b.w, b.depth)`; `distH = (b.h/2)/tan(fov/2)`; `distW = (span/2)/tan(fov/2)/aspect`; `dist = max(distH, distW)·1.6`; target `(cx, cy, 0)`; front `(cx, cy, dist)`; 3/4 `(cx + 0.55·dist, cy + 0.25·dist, 0.85·dist)`; reset each wall group rotation to stored rot; `controls.update()`.

**A8. Window → CSS3D segment mapping (`applyWindowRect`).** `cyIn = totalH/2 − rect.y·IN_PER_PX_H − rect.h·IN_PER_PX_H/2`; `zOff_front = −(1 + 0.01 + winIdx·0.005)`, back `+same` with rotation +π. Per segment i: `extL/extR = min(tan(|angle|/2)·1, 12.5625)` for corners at startCol−1 / endCol; `segInW = segCols·25.125 + (segCols−1)·gap`; `extSegInW = segInW + extL + extR`; `segIppx = extSegInW/(segCols·344)`. Segment px range `[startCol·344, (endCol+1)·344)` ∩ `[rect.x, rect.x+rect.w)`; empty → hide object. Container: width = overlapW px, height = rect.h px, overflow hidden, clip-path (F26). Inner: absolute; normal: width rect.w, height rect.h, `left = −(overlapLeft − rect.x)`, top 0, object-fit contain (scaled) / fill; span: width totalW, height totalH, `left = −(offsets[wall] + overlapLeft − rect.x)`, `top = −(totalH − wallHPx)`, fill. Placement: `(segCx, segCz)` midpoint; `clipCenterPx = overlapLeft + clipW/2`; `segCenterPx = segStartPx + segCols·344/2`; `miterShift = (extR − extL)/2`; `offsetIn = (clipCenterPx − segCenterPx)·segIppx + miterShift`; `wx = segCx + offsetIn·cos − zOff·sin`; `wz = segCz − offsetIn·sin − zOff·cos`; `obj.position = (wx, cyIn, wz)`; `obj.scale = (segIppx, IN_PER_PX_H, segIppx)`; `obj.rotation.y = rotY (+π back)`.

**A9. 3D hit → wall pixel (`worldToWallPixel`) and hit test.** For each column: `dx = p.x − col.x; dz = p.z − col.z; localX = dx·cos(−rotY) − dz·sin(−rotY)`; if `|localX| ≤ 12.5625 + 0.5`: `fracX = (localX + 12.5625)/25.125`; `px = c·344 + round(fracX·344)`; `py = round((totalH/2 − p.y)/IN_PER_PX_H)`; clamp to `[0, wallWPx−1] × [0, wallHPx−1]`; return; else null. Caveat: p must be in wall-local space (v1 passes world space). `windowAtPixel`: iterate windows last→first; first with `px ∈ [x, x+w) && py ∈ [y, y+h)`.

**A10. Dimension drawing & sprites.** For edge P0→P1 with outward normal n and (extGap g, offset o, overshoot v, tick t, label l): extension lines `P + n·g → P + n·(o+v)` at both ends; dimension line `P0 + n·o → P1 + n·o`; ticks ±t perpendicular at both ends; label at midpoint + n·(o+l). Custom: g .8, o 3, v .6, t .8, l 1.6; length = span·panel + (span−1)·gap. Rect: g 1, o 4, v 1.5, t .8, l 2.5; built in segment-local X then transformed by segment centre/yaw; all at z 1.15. `computeShapeEdgeRuns`: for each filled cell and each empty 4-neighbour record a unit edge keyed by (perpIdx, side); sort along-axis indices, merge consecutive into runs `{axis:'h'|'v', nx, ny, perpIdx, fromIdx, toIdx}` (h: ny +1 top / −1 bottom; v: nx −1 left / +1 right); handles holes uniformly. `createDimSprite(text)`: measure bold 56 px Courier New; canvas `(w+40) × (56·1.4+40)`; rgba(0,0,0,.8) roundRect r10 (fillRect fallback); text `#00ccff` centred; CanvasTexture LinearFilter; SpriteMaterial transparent depthTest off; renderOrder 999; scale `(6·aspect, 6, 1)`; `userData.dimBaseH = 6, dimAspect`. Per frame: `scale = max(0.4, |cam − target|/200)`.

**A11. Cover-fit photo drawing.** `ar = natW/natH; cAr = W/H`; if `ar > cAr`: `dh = H, dw = H·ar, dx = (W−dw)/2, dy = 0` else `dw = W, dh = W/ar, dx = 0, dy = (H−dh)/2`; `drawImage(img, dx, dy, dw, dh)` (offset by −cropX/−cropY for recording).

**A12. EXIF focal → FOV (`readExifFocal35`).** Read first 256 KB; require SOI 0xFFD8; walk markers (`0xFF`, marker, BE uint16 size); APP1 (0xE1) with 'Exif' at off+4: `tiff = off+10`; little-endian if uint16(tiff) === 0x4949; `ifd0 = tiff + uint32(tiff+4)`; scan IFD0 entries (count uint16, 12 bytes each from ifd0+2) for tag 0x8769 → `exifPtr = tiff + uint32(entry+8)`; scan Exif IFD for tag 0xA405 → SHORT at entry+8. Only the first APP1 inspected; exceptions → null. `vfov = 2·atan(halfMM/f35)·180/π`, halfMM 12 (landscape) / 18 (portrait by decoded dims); round; clamp 8..110.

**A13. Two-vanishing-point camera solve (`perspSolve`).** Intersection: `d = (x1−x2)(y3−y4) − (y1−y2)(x3−x4)`; `|d| < 1e-9` → null; `a = x1y2 − y1x2; b = x3y4 − y3x4`; VP = `((a(x3−x4) − (x1−x2)b)/d, (a(y3−y4) − (y1−y2)b)/d)`. vpX = ∩(l0,l1), vpZ = ∩(l2,l3). Centre: `u = x − W/2, v = −(y − H/2)`. Both finite: `f² = −(uX·uZ + vX·vZ)`; reject if `f² ≤ 100`; `f = √f²`. Either at infinity: `f = (H/2)/tan(camera.fov·π/360)` and that axis = in-image direction of the pair's first line `(dx, −dy, 0)`. `wx = normalize(uX, vX, −f)`; `recede = normalize(uZ, vZ, −f)`; `wz = −recede`; if `wx.x < 0` negate wx; if `wz.z < 0` negate wz; `wx = normalize(wx − wz·(wx·wz))`; `wy = wz × wx`; if `wy.y < 0` negate wx and wy. `camera.quaternion.setFromRotationMatrix(makeBasis(wx, wy, wz).transpose())`. FOV `2·atan((H/2)/f)` deg, rounded, clamped 8..110. `target = camera.position + forward·dist` (dist = |cam−target| or 300). Principal point assumed at viewport centre; square pixels. Position unsolved.

**A14. Codec sniff & decode path.** Read first 256 KiB as latin1; hevc = 'hev1'|'hvc1'; h264 = 'avc1'|'avc3'; av1 = 'av01'; vp9 = 'vp09'; exception → null. `pickVideoDecodePath`: null → 'video'; hevc && !canPlayType(`video/mp4; codecs="hvc1.1.6.L93.B0"`) && !canPlayType(`...hev1.1.6.L93.B0`) → `'VideoDecoder' in window ? 'webcodecs' : 'unsupported'`; else 'video'.

**A15. HEVC pipeline.** Poll for `MP4Box` (50 ms). `mp4file = MP4Box.createFile()`; onReady: track = videoTracks[0]; `durationUs = info.duration/info.timescale·1e6`; canvas sized to track dims capped at `gpuMaxTextureSize||4096` (uniform); `description = extractHEVCDescription(mp4file, track.id)` (trak.mdia.minf.stbl.stsd.entries → first with `.hvcC` (or `.avcC`); DataStream from `window.DataStream|window.MP4BoxStream|MP4Box.DataStream|MP4Box.MP4BoxStream`; `new DataStream(undefined, 0, BIG_ENDIAN)`; `box.write(ds)`; `new Uint8Array(ds.buffer).slice(8)` drops the 8-byte box header); probe codec candidates with `VideoDecoder.isConfigSupported({codec, description})`; `decoder = new VideoDecoder({output, error})`; `configure`; `setExtractionOptions(track.id, null, {nbSamples:30}); start()`. onSamples: `EncodedVideoChunk({type: is_sync?'key':'delta', timestamp: cts·1e6/timescale, duration: duration·1e6/timescale, data})` → decode. Feed: 4 MiB slices with `buf.fileStart = off` → `appendBuffer`; progress `min(99, round(off/total·100))`; `flush()`. Presentation: first frame sets `firstFrameAt = performance.now()`, `firstPtsUs`; queue; rAF `displayLoop`: `elapsedUs = (now − firstFrameAt)·1000`; pop frames with `(pts − firstPts) ≤ elapsed + 16000`, close all but the newest, draw newest, `shim.currentTime = (pts−firstPts)/1e6`, `readyState = 4`, markDirty. Loop: when `currentTime·1e6 ≥ durationUs − 200000` and queue empty → reset t0/pts0, `mp4file.stop(); mp4file.start()`. Cleanup: stop, cancel rAF, close queued frames, `decoder.close()`, `mp4file.stop()`.

**A16. Pixel-grid auto-visibility.** `camDist = distanceToSelectedWall()`; `fadeStart = threshold + 36`; `inBand = camDist ≤ fadeStart`; `opacity = inBand ? clamp((fadeStart − camDist)/36, 0, 1) : 0`. Write `uOpacity` to every active grid material; if any changed → `applyBrightness(state.brightness)`. If `inBand === _gridAutoVisible`: markDirty when in band; return. Else set flag; for every wall (activate context) `buildPixelGrid(computeColumnLayout(), wallDims(), wallFilledCells(wall))` on entry or `_removeAllGrids()` on exit; restore; write current opacity to fresh materials; re-apply brightness. `_removeAllGrids`: remove, dispose `uMaskTex`, material (if `_isPixelGridMat`), geometry.

**A17. Perpendicular distance to the selected wall.** `ctx.group.updateMatrixWorld()`; `p = group.worldToLocal(camera.position.clone())`; `dist = max(0, (|p.z| − 1)·(wall.scale||1))`; fallback `camera.position.distanceTo(controls.target)`. Exposed as `window.__distToWall`.
